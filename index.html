CSS Button Animation

Fill Slide

Hover to slide the color across the button.

CSS · Fill Slide · :hover
/* Fill Slide */

.fill:before {
  content: "";
  position: absolute;
  inset: 0;
  background: #00d9ff;
  transform: translateX(-105%);
  transition: transform .45s ease;
}

.fill:hover:before {
  transform: translateX(0);
}

.fill:hover {
  color: #03131b;
  box-shadow: 0 0 28px rgba(0,217,255,.35);
}

.fill:hover .triangle {
  transform: translateX(5px);
}

Pulse Glow

Hover to create a continuous neon glow.

CSS · Pulse Glow · :hover
/* Pulse Glow */

.pulse:hover {
  animation: pulseGlow 1s infinite;
  background: rgba(192,132,252,.08);
}

.pulse:hover .triangle {
  transform: scale(1.3);
  filter: drop-shadow(0 0 9px #c084fc);
}

@keyframes pulseGlow {
  0%,100% {
    box-shadow: 0 0 5px rgba(192,132,252,.2);
  }
  50% {
    box-shadow: 0 0 30px rgba(192,132,252,.75);
  }
}

Border Draw

Hover to draw an animated double border.

CSS · Border Draw · :hover
/* Border Draw */

.draw {
  border-color: transparent;
}

.draw:before {
  content: "";
  position: absolute;
  inset: 0;
  border: 2px solid #fb7185;
  clip-path: inset(0 100% 0 0);
  transition: clip-path .5s ease;
}

.draw:after {
  content: "";
  inset: 0;
  border: 2px solid #f59e0b;
  clip-path: inset(0 0 0 100%);
}

.draw:hover:before,
.draw:hover:after {
  clip-path: inset(0);
}

3D Pop

Hover and click for a realistic 3D button.

CSS · 3D Pop · :hover
/* 3D Pop */

.pop {
  background: linear-gradient(145deg,#142033,#08101c);
  box-shadow:
    inset 0 1px 0 rgba(255,255,255,.08),
    0 8px 0 #02050a,
    0 15px 25px rgba(0,0,0,.35);
}

.pop:hover {
  transform: translateY(-5px) scale(1.04);
  box-shadow:
    inset 0 1px 0 rgba(255,255,255,.12),
    0 14px 0 #02050a,
    0 25px 35px rgba(132,204,22,.18);
}

Rotate Loop

Hover to rotate the triangle continuously.

CSS · Rotate Loop · :hover
/* Rotate Loop */

.rotate:hover {
  box-shadow: 0 0 28px rgba(34,211,238,.35);
}

.rotate:hover .triangle {
  animation: rotateTriangle .8s linear infinite;
}

@keyframes rotateTriangle {
  to {
    transform: rotate(360deg);
  }
}
